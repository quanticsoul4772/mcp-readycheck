# Security Policy

## Supported Versions

Only the latest released minor version (currently the 1.0.x line, as declared in `package.json` as version 1.0.0) and the current `main` branch receive security fixes. Older versions are unsupported.

| Version        | Supported |
| -------------- | --------- |
| 1.0.x / `main` | Yes       |
| Older versions | No        |

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub's private vulnerability reporting (security advisory) flow:

1. Open the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Fill in the advisory form with as much detail as you can.

You can also go directly to the advisory form: <https://github.com/quanticsoul4772/mcp-readycheck/security/advisories/new>

**Please do not open public issues or pull requests to report vulnerabilities.** Public reports can expose users before a fix is available.

### What to expect

This is a best-effort, non-binding expectation: we aim to acknowledge reports within a reasonable time, investigate, and work with you on a fix. We follow coordinated disclosure, so please allow time for a fix to be released before sharing details publicly. Reporters are credited in the published advisory if they wish.
